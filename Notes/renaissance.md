
### **Control Structures** 
Control structures in programming are fundamental constructs that determine the order in which instructions are executed within a program. They allow programmers to manage the flow of logic, make decisions, and repeat actions, leading to the creation of dynamic and responsive software.

## **Conditional Structures**
These structures allow the program to make decisions based on certain conditions. 

## **Iterations(Loops)**
These structures enable the repeated execution of a block of code multiple times, either for a specified number of repetitions or until a certain condition is met. Common examples include:
For loops: Iterate a specific number of times, often used when the number of iterations is known in advance.

for (initialization; condition; increment/decrement) {
  // Code to execute
}
# Nested Loops
### **Generating all possible pairs from two lists**
list1 = ['A', 'B']
list2 = [1, 2, 3]
for item1 in list1:
    for item2 in list2:
        print(f"({item1}, {item2})")

While loops: Continue executing as long as a specified condition remains true.

while (condition) {
  // Code to execute
}

let num = 1;
while (num <= 5) {
  console.log(`Number: ${num}`);
  num++; // Increment num to avoid infinite loop
}

Do-While loops: Similar to while loops, but guarantee that the loop body executes at least once before the condition is checked.

let count = 6;
do {
  console.log(`Count: ${count}`);
  count++;
} while (count <= 5); // Output: 6 (runs once even if condition is false)

do {
  // Code to execute
} while (condition);
